# QQ 农场「青酿换万金」活动源码

本仓库只保留 QQ 农场「青酿换万金 / 青梅」活动相关源码片段，已去掉与活动无关的完整工程代码。

## 文件说明

```text
frontend/qingmei-activity-ui.js       青梅活动页面渲染与按钮参数逻辑
frontend/qingmei-activity.css         青梅活动页面样式
backend/qingmei-activity-service.js   青梅活动后端核心逻辑：自动选背包青梅、领取状态、操作参数
tests/qingmei-activity-service.test.js 后端核心逻辑测试
```

## 功能范围

- 每日青梅种子领取状态展示。
- 已领取后按钮置灰。
- 背包普通青梅自动全选。
- 酿造并出售、继续精酿、售出领奖三个按钮。
- 普通青梅不走仓库普通出售，由活动流程处理。

## 注意

这是活动源码摘录包，不是完整可运行项目。接入时需要把这些函数合并到你自己的活动页面和活动服务里，并复用你工程里已有的请求、日志、状态管理和构建流程。
