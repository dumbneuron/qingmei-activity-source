# Publication boundary

Included: activity-only source, public item IDs and rules, public art URL indexes,
tests with synthetic parameters and documentation. No image binaries are bundled.

Excluded: account and user databases, activation cards, credentials, login codes,
session tokens, native share payloads, real friend profiles and avatars, screenshots,
raw traffic captures, certificates and private keys, logs, deployment settings,
machine paths, author email, original repository metadata and Git history.

No demo server, account service, database or deployment environment is bundled.

Asset URLs contain public CDN resource identifiers, not user identifiers.
Activity and item identifiers are public protocol constants, not account IDs.
Original source comments containing capture metadata have been omitted.

Only this directory belongs in an activity-source publication. Keep runtime data,
transport credentials and any future real captures outside the repository.
